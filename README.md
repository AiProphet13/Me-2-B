## How It Works

1. Open Me-2-B on your device
2. 2. One person creates a room (gets a passphrase)
   3. 3. Other person enters the passphrase
      4. 4. Connected — voice, text, and files are encrypted peer-to-peer via WebRTC
        
         5. No data touches a server. Everything stays between you and the person you're talking to.
        
         6. ## Features
        
         7. - Voice calls (peer-to-peer, encrypted)
            - - Text messaging
              - - File and image sharing
                - - Works across platforms (phone talks to PC, browser talks to app)
                  - - No accounts, no sign-ups, no tracking
